# Laby — Dokumentasi

Direktori ini berisi dokumen referensi, perencanaan, dan panduan teknis untuk proyek **Laby** (aplikasi laporan keuangan pribadi berbasis double-entry bookkeeping).

---

## Daftar Dokumen

| File | Isi |
|---|---|
| [`laby-planning.md`](./laby-planning.md) | Visi produk, fitur utama, bagan akun, skema DB, tech stack, roadmap, dan keputusan arsitektur |
| [`setup-dev.md`](./setup-dev.md) | Onboarding lokal: install, konfigurasi `.env`, setup database, seed, dan perintah yang sering dipakai |
| [`ai-prompt-engineering.md`](./ai-prompt-engineering.md) | System prompt, skema JSON output, dan panduan implementasi untuk fitur ekstraksi screenshot dan parsing chat Gemini |
| [`standar-akuntansi-referensi.md`](./standar-akuntansi-referensi.md) | Referensi standar akuntansi Indonesia (SAK/PSAK), kode akun, siklus akuntansi, dan konvensi penulisan angka |
| [`rencana-lapor-pajak-spt.md`](./rencana-lapor-pajak-spt.md) | Panduan pajak untuk freelancer/pemilik usaha: PPh pribadi vs badan, timeline SPT, langkah pelaporan via Coretax |
| [`gemini-api-free-tier-cheatsheet.md`](./gemini-api-free-tier-cheatsheet.md) | Cheatsheet Gemini API: model aktif di free tier, rate limit, cara dapat API key, dan alternatif provider |

---

## Konvensi Penamaan

Semua file menggunakan format `kebab-case` dalam Bahasa Indonesia, mendeskripsikan isi dokumen secara langsung.
